# APEX HUB

Apex Legends companion website in development.

## Current status

The interactive alpha is being developed in Floot. This repository is the source-control home for the project.

## Planned features
- Weapon database with detailed weapon stats
- Current-season and historical weapon meta archive
- Legends, team compositions and guides
- Ranked tools and map rotation
- Damage calculator
- Player statistics lookup

## Data integrity
Only verified, current-patch data should be presented as factual. Unverified weapon values, rankings, and rotation data must not be invented.

## Deployment
Not published yet. Do not deploy publicly until the owner explicitly approves launch.
